# Amar Shaw — Healthcare RCM to Full-Stack Pitch-Deck

An executive-level interactive presentation platform and portfolio built with **Vue 3 (Composition API)**, **TypeScript**, **Vite**, and **Tailwind CSS**.

---

## ⚡ Architecture & Features

- **Strict TypeScript Architecture**: 100% typed data contracts and global interfaces (`src/types/index.ts`) ensuring zero runtime errors.
- **6 Dedicated Modular Slides**:
  - `src/slides/1-hero/`: Profile photo, core value proposition, and key domain metrics.
  - `src/slides/2-career/`: 5+ years track record (RCM Workshop, Value RCM, Sunknowledge, Fusion BPO).
  - `src/slides/3-projects/`: Healthcare RCM Dashboard (React), Claims Code Audit Automation (Python), and this Pitch-Deck.
  - `src/slides/4-cost-roi/`: Interactive live ROI & startup cost savings simulator.
  - `src/slides/5-tech-stack/`: Frontend, Backend, and Healthcare Domain skill matrix.
  - `src/slides/6-contact/`: Verified LinkedIn, GitHub, Email, and availability status.
- **Dynamic Responsive Background**: Automatically switches between **16:9 Landscape** (Desktop) and **9:16 Portrait** (Mobile).
- **100% Viewport Lock (`100dvh`)**: App-like pitch-deck experience with zero redundant scrolling.
- **Dual Navigation**: Keyboard arrow controls (`←` / `→`) on desktop and smooth touch swipe gestures on mobile.

## 🚀 Quick Start Guide

```bash
# Clone the repository
git clone [https://github.com/amarshaw87/amar-rcm-to-fullstack.git](https://github.com/amarshaw87/amar-rcm-to-fullstack.git)

# Navigate into directory
cd amar-rcm-to-fullstack

# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production with strict type-checking
npm run build
