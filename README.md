# Amar Shaw — Healthcare RCM to Full-Stack Pitch-Deck 👨‍💻

An executive-level interactive presentation platform and portfolio built with **Vue 3 (Composition API)**, **TypeScript**, **Vite**, and **Tailwind CSS**. Engineered specifically to demonstrate how 5+ years of deep US Healthcare Revenue Cycle Management (RCM) domain expertise translates into high-impact full-stack software solutions.

---

## ⚡ Technical Architecture & Engineering Features

*   **Strict TypeScript Core:** 100% strictly typed data contracts and unified global interfaces (`src/types/index.ts`) guaranteeing complete compile-time validation and zero runtime state exceptions.
*   **Cinematic Sci-Fi Visual Layer:**
    *   **Interactive Starfield Canvas:** High-performance HTML5 Canvas subsystem rendering dynamic cosmic dust configurations with physics-based mouse-follow repulsion vectors and automated shooting star/meteor trajectories.
    *   **Corner-Triggered 3D Tilt Physics:** Fine-tuned 3D depth perspective bounding sensor restricted to a `60px` perimeter border zone. Listens to discrete desktop `click` and mobile touch `dblclick` events, automatically returning to flat `0deg` matrix alignment after `1.2s` via automated recovery timers.
    *   **Pulsing Glow Animation Nodes:** Custom Tailwind CSS keyframe integrations (`animate-pulse-glow`) providing fluid, breathing neon auras around critical active workstation view sections.
*   **100% Viewport Vector Lock (`100dvh`):** Fully isolated layout environment engineered to constrain all functional pipelines inside adaptive responsive frames, completely eliminating scroll fragmentation or unwanted sub-container layout overflows.
*   **Dual-Navigation Highway System:** Integrated global desktop event listeners mapping hardware controls (Keyboard Arrow keys `←` / `→` and `Page Up` / `Page Down`) alongside highly responsive swipe velocity gesture calculation algorithms on touch layout viewports.

## 🚀 Quick Start Guide

### 1. Clone the repository environment
```bash
git clone https://github.com/amarshaw87/amar-rcm-to-fullstack.git
cd amar-rcm-to-fullstack
```

### 2. Set up local dependency branches
```bash
npm install
```

### 3. Launch local real-time development engine
```bash
npm run dev
```

### 4. Optimize code distribution bundle with strict type-checking
```bash
npm run build
```
